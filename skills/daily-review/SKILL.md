# Daily Review（每日复盘）

## 作用

读取当前 Claude Code 会话的对话内容，按目标岗位画像做对标分析，生成结构化日报。**目标是积累简历素材 + 识别能力缺口**，让用户在日常工作中有意识培养目标岗位所需能力。

## 触发方式

- **手动（v1，当前）**：会话末尾说 `/daily-review` 或 "做一下今天的复盘"
- **本地 cron（v2，待建）**：跨会话聚合 `~/.claude/projects/**/*.jsonl`

## 执行步骤

执行此 skill 时，按以下顺序操作：

1. **读取目标画像**：读 `skills/daily-review/role-rubric.md`，理解当前对标岗位
2. **读取输出模板**：读 `skills/daily-review/report-template.md`
3. **分析当前会话**：基于已在 context 中的对话历史，提取：
   - 完成的具体任务（按主题归类）
   - 涉及的技术栈、工具、概念
   - 出现过的"不会/不熟/卡住"的场景
4. **生成日报**：按模板填充内容，写入 `daily-reports/{YYYY-MM-DD}.md`
   - 文件名用今天的日期
   - 如果同日文件已存在 → **合并追加**，不要覆盖（保留早上的内容，追加下午的）
5. **输出简短摘要**：告诉用户"已生成 X 月 X 日日报"，列出 3 个核心 bullet（最重要的简历素材、最大的缺口、明日建议）

## 输出原则（重要）

### 简历素材必须可量化
- ❌ "学习了 RAG 系统"
- ✅ "搭建了一个基于 Milvus + bge-large-zh 的 RAG 原型，召回 top-5 准确率 78%"
- ❌ "用了 Claude API"
- ✅ "用 Claude API 实现了多轮对话 agent，单次响应 P50 1.2s，token 成本 $0.003/对话"

如果对话内容**确实没有可量化成果**，宁可写"今日无简历级素材"，也不要硬凑。

### 能力缺口必须对应画像具体技能项
- ❌ "基础不扎实"
- ✅ "缺口：Agent Memory 设计（对应 role-rubric § Agent 高阶能力）。今天做对话 agent 时不知道怎么管理长对话上下文"

每个缺口必须给一个**具体学习资源**（论文 / 文档 / 仓库 / 课程）。

### 明日建议必须可执行
- ❌ "继续学习 AI agent"
- ✅ "明天花 1 小时跑 LangGraph 官方 quickstart，体验 state machine 写法"

### 不夸大成果
- "今天初步学习了 X" 不能写成"掌握了 X"
- "我搭了个 demo" 不能写成"完成了生产级实现"

### 不要堆原文
- 不要把对话原文塞进日报
- 只提炼"信号"——做了什么、暴露了什么、学到了什么

## 边界

- **不主动 commit**：生成文件后告诉用户，让用户自己决定是否 commit
- **不评价用户**：只描述事实和差距，不给"你今天表现不错/不好"这类评价
- **不替用户决定职业方向**：role-rubric 是用户给的，跟着它对标就行，不要扩展到其他岗位
